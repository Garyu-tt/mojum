Формат mojum.world.point-room-draft/1. Экспорт создаёт только файл конфигурации, не запускает симуляцию.

Сохраните как room.json

После сохранения файл можно проверить командой PYTHONPATH=src python -m mojum.room_input room.json, а затем создать новый SQLite-журнал с --room-numeric-contract typed_v1 --new-room-contract room.json. Не указывайте существующий журнал: его нужно восстанавливать через отдельный защищённый режим.
