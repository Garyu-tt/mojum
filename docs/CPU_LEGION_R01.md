# CPU Legion R0.1: portable, local CPU coding worker

**Deployment target:** unassigned. No host, VM or server is authorized for deployment by this change.
**Dependencies:** The coordinator and mandatory attempt fencing were accepted into `main` through merged PR #477; separate #488 is superseded.
**Current state:** CPU-only worker proposed for independent acceptance in PR #489, with #499 no-redirect/no-proxy hardening forward-ported. This is not a confirmed running model service or a deployed legion.

The worker is a host-neutral **local** adapter for an OpenAI-compatible inference endpoint,
for example a CPU-only llama.cpp server with a compact coding GGUF model. Its model
API accepts only numeric loopback (`127.0.0.1` or `[::1]`), disables
environment-configured HTTP proxies, and rejects every HTTP redirect, including
redirects to another local path. Configure the server URL directly; DNS names
such as `localhost` and redirecting proxies are deliberately unsupported. No
cloud LLM credentials or GitHub write token belong in the model worker's
environment. The worker must never run commands generated by the model,
execute candidate tests in its own credential scope, push commits, approve PRs
or merge proposals.

Each worker atomically leases one task from the Spartan coordinator, reads up to
five explicitly assigned tracked Python files, requests a small unified diff,
checks file scope and `git apply --check`, and writes a private 0600 patch
artifact. A **separate isolated runner** must verify that the submitted patch
matches its recorded digest, execute the relevant tests without model
credentials, and create a draft PR. Independent QA/SHIP alone decides whether
the exact tested HEAD and BASE are safe to integrate.

The runner caps active jobs to the minimum of requested worker slots, configured
model-server concurrency, estimated CPU capacity and free RAM minus a 2 GiB
reserve. This is an admission estimate, not a benchmark or proof of real
simultaneous inference. `--workers 300` means a **300-slot address space**,
not 300 resident LLMs. Use a separate measured concurrency probe before any ramp.

## Host-neutral activation checklist

1. Select a host explicitly through approved infrastructure inventory; do not
   infer placement from previous experiments, stale host names, IP addresses,
   or an unauthenticated SSH scan. No remote connection is initiated by this PR.
2. Verify host identity through a trusted control plane before remote access.
   Keep SSH host-key verification enabled; never embed fingerprints in this
   deployment template.
3. Inspect the selected host's permitted CPU quota, cgroup memory limits,
   available RAM and storage. Benchmark actual model memory use, throughput,
   latency and quality at 1, 2, 4, 8 concurrent sequences. Lower concurrency
   on OOM, swap thrashing, thermal throttling or excessive latency.
4. Use an unprivileged service account, read-only checkout, restricted artifact
   directory, and per-worker task/file allowlists. Bind the inference endpoint
   exclusively to numeric loopback; isolate its process and retain the enforced
   proxy/redirect rejection before enabling real model calls.
5. Place the coordinator and local workers on a single host for the first
   smoke test. Do **not** share a live SQLite WAL database across hosts.
   Multi-host scheduling requires a fenced authenticated coordination service
   with lease fencing and idempotent artifacts; do not independently run two
   coordinators against copies of the same work queue.
6. Wire generated patch artifacts to a credential-isolated test/publisher
   pipeline and the existing exact-head/base independent merge acceptance.
   First run with an empty queue and inspect reported `actual_parallel_limit`.
   Add one bounded non-production task before scaling.

## Example for an explicitly approved local host

These are example **local commands**, not evidence of a performed deployment.
Paths and model ID must be set by the operator on the chosen host.

```sh
python3 tools/spartan_coordinator.py --db /var/lib/mojum/legion.sqlite3 init --slots 300
python3 tools/cpu_legion.py --db /var/lib/mojum/legion.sqlite3 \
  --repo /opt/mojum --out /var/lib/mojum/patches \
  --model LOCAL_MODEL_ID --workers 300 --model-parallel 1
```

The source worker only writes patch artifacts; it does not start an inference
server, run tests, publish PRs, guarantee 300 active model calls, or deploy to
any infrastructure. All PRs remain subject to CI, review and branch policy.
