# Mojum offline graph preview R0.1

This is the browser-preview sub-slice of issue #699. It complements the
stdlib projection/CAS bridge (Draft PR #723) and deliberately does not
implement React Flow or Rete runtime packages.

## Run

Open `tools/graph_preview/index.html` directly in a modern browser. Generate
an envelope first with the `mojum.graph_editor_cli export` commands in
[GRAPH_EDITOR_BRIDGE_R01.md](GRAPH_EDITOR_BRIDGE_R01.md). No local server,
npm install, network, or third-party asset is required.

## Behavior

The page accepts one `mojum.graph-editor-envelope/1` JSON file and renders
a read-only, keyboard-selectable diagram. It supports both the React Flow
and Rete-shaped edge/node records generated by the bridge. Node selection
shows the supplied visibility, typed ports, config, notes, and coordinates.
The filter narrows nodes and connected edges without modifying source data.

It fails closed for unsupported envelope structure, duplicate/missing node
IDs, mismatched canonical node inventory, unsupported visibility, invalid
positions, unknown edge endpoints, excessive file size, and excessive
node/edge counts. The layout is taken from the projection positions when
present, otherwise a deterministic four-column fallback is used.

## Security and privacy

- Local file only; no API calls or remote assets.
- Maximum input is 512 KiB; up to 256 nodes and 2048 edges.
- User-supplied values are inserted as SVG/text nodes with `textContent`.
  There is no `innerHTML`, `eval`, dynamic code, or remote script.
- The preview does not validate a graph's cryptographic authenticity. The
  displayed SHA is a caller-supplied identifier from the envelope.
- PRIVATE and RESTRICTED records are not exported by this tool; however,
  opening an already-exported private envelope exposes that file in the
  local browser tab. Protect the source file and browser profile.
- No editor writeback, CAS approval, graph execution, hot swap, journal,
  Noosphere, production, or hardware access exists.

## Resource budget and QA

The renderer keeps one bounded JSON document and an SVG projection in memory.
Its limits are conservative for a local desktop/mobile browser; actual FPS,
heap use, and large-graph usability have not been measured. This is a viewer,
not a graph editor.

Run the hermetic static contract tests:

```sh
python -m unittest discover -s tests -p 'test_graph_preview.py' -v
```

The suite verifies the offline single-file packaging and key browser security
invariants. Browser automation / mobile performance and the repository's
full CPython 3.11-3.13 CI still require independent exact-head verification.
