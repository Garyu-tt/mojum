# Executor extraction R01

Stacked migration candidate on #1545; not a new product feature. Legacy graph execution order, virtual clock and staged effects are extracted into a domain-neutral core. Tests compose the six legacy domain handlers outside core and compare 120 steps, outputs, episodes and tick with pinned legacy. A late failure leaves the executor clock unchanged and exposes no staged effects to the caller.

Scope: trusted synchronous pure handlers only. No arbitrary Python sandbox, stateful/external handler rollback, durable commit, release loader, snapshot schema, replay restore or full legacy regression parity claimed. Existing legacy snapshot and restore stay unchanged. A later extraction must pin handler identity and preserve zero/multiple-sink replay semantics, canonical hashes, and old checkpoint compatibility at the adapter boundary. Core tick currently advances after successful evaluation, not durable commit; durable transactional semantics require a separate caller protocol before use with Noosphere. The JSON structural and wire budgets are candidate limits, not established legacy compatibility guarantees. Independent review and CI required before promotion.
