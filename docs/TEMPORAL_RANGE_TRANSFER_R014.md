# R0.14 — temporal near-field learning, transfer and negative controls

**Evaluation only.** Offline, deterministic CPU/stdlib test of whether measured *changes in range* after movement are predictive for another color and another position. No modification to the canonical Aquarium, GENESIS, Noosphere, actuators or private event history. The R0.13 integration candidate #75 remains the parent.

## Reproduction

`PYTHONPATH=src python -m mojum.temporal_range_benchmark`

`PYTHONPATH=src python -m unittest discover -s tests -p test_temporal_range_benchmark.py -v`

All observations are generated by existing `ToyScene.sense` on real numerical point-room transitions from `world_room.advance`. Before each transition, the model receives only strictly validated 10-cm range bucket and chosen signed 10-cm X displacement; it never receives object ID, exact object coordinates, RGB, material, softness, future pose, or obstacle rectangles. It observes the next sensor reading after the synthetic movement. The 10-cm evaluation displacement is **larger than the canonical Aquarium's 4-cm motor-play budget** and MUST NOT be interpreted as an authorized physical command.

## Controlled comparison

Train three real synthetic range transitions from a red toy at x=1.2 with the observer starting at x=.8; record 3→2, 2→1, 1→0 after successive +.10m motion. The frozen initially empty model receives the same cues but is never updated; it returns **no model prediction**. A separate nonlearned baseline, *persistence*, predicts that the previous range bucket will not change.

Evaluate without updating either model:

| Held-out test | Observed next range | Learned next range | Baseline | Outcome |
| --- | --- | --- | --- | --- |
| Green RGB, different absolute x, start bucket 3 | 2 | 2 | 3 | Learned error 0, persistence error 1 |
| Green RGB, same sequence, start bucket 2 | 1 | 1 | 2 | Learned error 0, persistence error 1 |
| Green RGB, same sequence, start bucket 1 | 0 | 0 | 1 | Learned error 0, persistence error 1 |
| Orange RGB, **unseen initial bucket 4** | 3 | **None** | 4 | No learned coverage |
| Green RGB, **new wall blocks movement**, start bucket 3 | 3 | 2 | 3 | Learned error 1; persistence error 0 |

The benchmark compares squared errors in units of **10-cm distance bucket squared**, not meters or physical material properties. The frozen model's native prediction is None; the persistence baseline is a *separate comparator* and is never falsely attributed to it.

## What can and cannot be concluded

A learned transition keyed by numeric range and commanded motion is invariant to **toy color and absolute world coordinate** in these controlled scenes, so it transfers to a toy with unseen RGB. This is a narrow demonstration of *temporal sensory affordance reuse*, **not** object classification, broad generalization or physics understanding. There is no prediction for a never-seen initial bucket, and a hidden obstacle produces a wrong forecast. The selected motion and toy placements make a simple kinematic pattern; this small deterministic test does **not** establish statistical robustness, and the fixed persistence comparator is not an optimal policy.

The test is intentionally separate from the canonical R0.13 Aquarium to avoid breaking its versioned SQLite journal and its previous replay guarantees. Before runtime integration: add an opt-in versioned sensory adapter with a 4-cm-compatible action, collision-aware range transitions, a frozen/shuffled-outcome control and multi-seed held-out rooms, deterministic replay, after-CAS learner adoption, independent review, and no hidden spectator fields. No external hardware, phone, GPU, network or real-world motor authority was used.
