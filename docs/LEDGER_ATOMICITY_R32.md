# GenomeLedger migration correction R32

The candidate plugin preserves the legacy JSON schemas, content hashes and public methods. Append validates input and uses a lock for CAS, bounds, duplicate detection and publication. Event history, event ID index and computed revision are published together in one state tuple after allocations and hashing. Snapshot and phenotype capture the same coherent state. Nested inherited Mapping is normalized to dict; noncanonical values fail admission. Caller must not mutate supplied mappings during validation. This is in-memory atomic publication, not durable transactions; a process interruption after publication may commit without delivering a response. Concurrent writers using a stale revision must retry with a new revision. Existing legacy branch and pinned baseline remain unchanged. Previous integration pins remain historical; updated revision requires cross-core compatibility testing before promotion.
