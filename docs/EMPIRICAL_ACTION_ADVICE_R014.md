# R0.14 — опытный советчик движений, CPU-only

**Статус:** экспериментальный режим, подключён к **основному Aquarium** поверх PR #84, но не к `main`. Он использует существующую модель `RangeOutcomeMemory` и двигательный `Explorer`. Никаких аппаратных приводов, сетевых вызовов, GPU или дополнительного SQLite-журнала.

## Запуск

Без внешних зависимостей из корня репозитория:

`PYTHONPATH=src python -m mojum.aquarium --db ./dante_advised.sqlite3 --ticks 120 --exploration-mode goal_free --sensory-mode toy_probe --temporal-mode range_outcome --action-advice-mode learned`

С теми же аргументами и `--ticks 30` организм продолжает работу из существующей базы с полной проверкой прошлых событий. Установите `--neural-mode disabled`, если нужно отключить отдельного наблюдателя пульса. `--watch` выдаёт PRIVATE JSONL: не публикуйте такие записи в GitHub.

Контрольный вариант запускается **на новой отдельной базе** с `--action-advice-mode observe`. В нём `RangeOutcomeMemory` **по-прежнему обучается** на фактических столкновениях, но `Explorer` **не применяет** её советы при выборе действия. Это *замороженная политика применения подсказок*, **не** замороженная сенсорная модель. Для полного контроля без временной модели предусмотрен старый `--action-advice-mode none`; он не меняет R0.14 #84.

## Алгоритм

1. Сначала считывается текущий числовой признак `ToyScene.sense(world)`. Разрешены только категория дистанции и намерение `rest/x+/x-/y+/y-`. RGB, ID игрушек, мягкость, размеры стен, будущие состояния в таблице советчика **не используются**.
2. Из существующей `RangeOutcomeMemory` только для четырёх активных направлений извлекаются измеренные `blocked=True/False` предыдущих виртуальных попыток **в той же категории расстояния**. `rest` нельзя исключать.
3. Совет `avoid(action)` возможен **только после минимум двух измеренных попыток** и **только если все они закончились столкновением**. Одна успешная попытка отменяет исключение. При неизвестном или неоднозначном опыте советы пустые.
4. `Explorer` сохраняет свой исходный приоритет детской моторной игры, но пропускает советуемые для избегания действия. Его обычная память по позиционным зонам остаётся включённой; если безопасной альтернативы по текущим эвристикам нет, он возвращает `rest`.
5. Событие `aquarium.frame` сохраняет **одновременно** исходный числовой сенсор, подтверждения/счётчики всех кандидатов, `blocked_hints`, фактически применённые `applied_hints`, выбранное действие, реальное смещение и флаг столкновения. Всё остаётся в одном PRIVATE SQLite-журнале.
6. После успешного SQLite CAS обновляются память моторной политики и временной предиктор; при повторном открытии все советы **пересчитываются из ранее зафиксированной памяти до действия**, и только после этого воспроизводится новый опыт. Неправильные/подменённые события отклоняются. Недопустимый режим CLI не создаёт новую SQLite-базу.

## Проверенный сравнительный эксперимент

Две независимые точки (x=1.39 и x=1.40, y=2.0) у настоящей для синтетической комнаты AABB-стены дали **два реальных** измеренных заблокированных перемещения +4 см. Обе точки имеют одинаковую 10-см категорию расстояния до игрушки. Этого достаточно для совета избегать `x+`.

Затем две политики `Explorer` получают одинаковое новое состояние, но одна игнорирует подсказки:

| Политика | Выбранное действие | Фактическая проверка `world_room.advance` |
| --- | --- | --- |
| Контроль без применения советов | `x+` (+4 см) | Столкновение, позиция не изменилась |
| `learned` (по накопленным измерениям) | `y+` (+4 см) | Перемещение выполнено |

Это **фиксированный синтетический A/B-тест**, не доказательство улучшения в произвольном мире. Отдельные отрицательные тесты подтверждают, что одно столкновение недостаточно, одно успешное движение сохраняет направление доступным, а незнакомая дистанционная категория не генерирует подсказок.

## Что ещё не сделано

- Предсказатель — **консервативный советчик**, не аппаратный контур безопасности: он не должен управлять физическим телом, где нужен Motor Gate, аварийный останов и отдельная авторизация.
- Выбор признаков заранее задан программистом, их инвариантность к RGB **не открыта моделью автоматически**; категории 10 см грубы для движения 4 см.
- Нет достоверной геометрической карты, реального зрения/касания, нейронного мозгового управления, MuJoCo, распределённого исполнения или Android-сервиса.
- Совет по одной категории дистанции переносится только условно и **может быть ошибочным за новой стеной или в другой конфигурации**. Нужны оценки на множестве неизученных миров, сравнение накопительных столкновений, контролируемая неопределённость и дополнительная причинная калибровка.
- Нельзя считать тест `observe` полностью независимым *замороженным обучением*: его временная память обновляется точно так же, просто её совет не подключается к исполнительной политике.
