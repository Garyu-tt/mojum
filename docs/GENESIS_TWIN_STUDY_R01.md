# GENESIS Twin Study R0.1 — synthetic research contract

This is a **local in-memory fixture**, not a launched creature or a cognitive
experiment. It makes a future controlled "digital twins" study easier to
reproduce without forking Dante or opening an agent's PRIVATE SQLite history.

Run (Python 3.11+, stdlib only):

```sh
PYTHONPATH=src python examples/twin_study_demo.py
PYTHONPATH=src python -m unittest discover -s tests -p 'test_twin_study.py' -v
```

## What is implemented

- Two **new**, explicitly named participants with different `agent_id` values.
  Names must be chosen by people; no naming from genome or automated mentor
  selection. The input seed is cloned, never overwritten. Only `genome_id`
  changes per copy, so the shared `inherited_sha256` deliberately omits identity.
- Each copy has its **own GENESIS in-memory acquisition ledger**. An acquired
  change to A cannot affect B. The R0.1 GENESIS genes are only synthetic
  heartbeat, body scale and sensory gain, **not a brain, personality or body rig**.
- Separate, bounded (256 records per child) observer-provided scores in
  named study domains: e.g. art, music, games, spatial puzzles. Each record
  carries an event ID, subject ID, tick, integer score 0..1000, and a declared
  source. These scores are not generated by Mojum's brain and are not evidence
  of acquired intelligence.
- Optional jointly logged **meeting markers** (128 maximum); a meeting is
  recorded in the study but does not merge/copy histories or infer that an
  interaction happened in a virtual world. Later domain measurements can be
  compared before/after a marker, without attributing causal influence.
- Deterministic read-only `compare(study, tick=N)`: current synthetic
  phenotype parameters and **effective acquired-event counts at that tick** for both participants; A-minus-B deltas; latest
  externally scored domain values and their A-minus-B deltas. A score missing
  for either subject has delta `null`, **not zero**.
- Strict typed/size validation, duplicate and monotonically dated event
  checks, no retroactive acquisitions before already measured ticks, and a
  compare-and-swap revision on changes. Mutations return fresh objects, not
  edits of the inputs. Roundtrips validate every embedded GENESIS snapshot.

## Explicit nonclaims and next integration gates

1. **No agent brain or initial learned-state cloning.** Only inherited *fixture*
   parameter equality and empty acquired histories are proved. Future real
   same-start experiments need an atomic versioned multi-component snapshot:
   genome, learner, memory, body, simulated world, RNG and clock. Never call
   these R0.1 subjects "identical minds".
2. **No independent caretaker enrollment, authentication or storage isolation.**
   Independent histories are separate Python data structures only. Proper
   access controls, separate PRIVATE Noosphere stores, durable copies, privacy
   permissions and consent are future work.
3. **No cognitive learning or behavioral causality established.** Manual
   scores may be noisy or biased. Future real comparisons need matched probes,
   assessor blinding, controlled schedules, shared test sets, RNG controls,
   predeclared hypotheses and repeated replications.
4. **No actual cross-world communication.** Meetings are event markers only.
   Future encounters require explicit session consent, messages with
   provenance, and separate records of any later change in each participant.
5. The study revision is an **unkeyed SHA-256 checksum**, not a signature,
   authorization or tamper-proof external anchor. Snapshots are returned to
   the caller, not written to SQLite or exported. Treat them as PRIVATE
   research data if later populated with real individual observations.
6. No production Dante SQLite, live agent, system host, server, neural
   checkpoint, external service, or physical actuator is touched.

**R0.1 acceptance:** these functions and their local unit tests are useful
as a reproducible *experiment specification*; they are not sufficient for
Mojum organism release or a human-subjects study.
