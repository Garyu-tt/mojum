# Mojum R0.12 — движущиеся предметы внутри приватной виртуальной комнаты

**Опциональный CPU-only эксперимент** на базе R0.9–R0.11. Изменение вносит
настоящее изменение состояния синтетической комнаты **каждый виртуальный
такт**, а не подменяет отдельные наблюдения вручную в тестах. Это
кинематическая модель с заранее заданными скоростями и отражениями от
границ, **не MuJoCo, не динамическая физика и не обученная моторика**.

## Что реально происходит

- В комнате живут два синтетических предмета с собственными стартовыми
  положениями, RGB и скрытым «мягким» откликом.
- `MovingToyScene` вычисляет их текущие координаты из неизменяемого
  манифеста и номера виртуального такта. Скорость ограничена
  **0,05 м за такт**. При достижении границы координата отражается.
- Существо движется прежним ограниченным контроллером моторного
  экспериментирования; его обычный числовой датчик близости читает
  **текущее положение** ближайшего предмета (не готовые ID/название,
  не скрытое значение мягкости и не траекторию).
- При выборе `probe` числовой контактный результат соответствует
  текущему положению предмета **в том же такте**.
- `ProvisionalObjectMemory` продолжает делать только **гипотезы**
  (`h0001`, …) по наблюдённым RGB, дальности, азимуту и собственной
  позиции. Предмет может покинуть датчик и появиться вновь, перемещаться
  между наблюдениями и конфликтовать с прежними оценками.
- Локальный браузер `examples/sensory_observer.html` использует
  `spectator_scene` **для зрителя**, включая покадровые положения
  предметов. Агенту эти данные не предоставляются.

Это ещё не физическое тело: игрушки не сталкиваются друг с другом,
не имеют инерции и не подчиняются силам. Никакой доступ к оборудованию
не открывается.

## Запуск с приватной памятью

Из рабочей копии **этой ветки** (она зависит от PR #34):

```bash
PYTHONPATH=src python -m mojum.sensory_play \
  --db ./dante_moving_r12.sqlite3 \
  --moving-toys --object-tracking --contact-guard --rgb-tolerance 1 \
  --ticks 180 --watch > ./dante_moving_r12_private.jsonl
```

Откройте локальный `examples/sensory_observer.html`, выберите файл
`dante_moving_r12_private.jsonl`. Наблюдайте за перемещением объектов,
сенсорными сигналами, проверками контакта и неполными гипотезами.
Этот просмотр **не** доказывает подлинность JSONL и не является
просмотром «мыслей».

Продолжение одного и того же опыта:

```bash
PYTHONPATH=src python -m mojum.sensory_play \
  --db ./dante_moving_r12.sqlite3 \
  --moving-toys --object-tracking --contact-guard --rgb-tolerance 1 \
  --ticks 180 --watch >> ./dante_moving_r12_private.jsonl
```

При повторном запуске нельзя забыть `--moving-toys` или поменять
скорости и сценарий в коде. Начальная конфигурация сцены включена
в PRIVATE bootstrap Noosphere, и на открытии хранилища проверяется
её совпадение с текущей конфигурацией. Все факты опыта
детерминированно воспроизводятся на CPU при восстановлении журнала.
После неудачного CAS-записывания текущее локальное состояние
мира, RNG и обучаемой памяти не обновляется.

## Независимые доказательства и пределы

`tests/test_moving_toys_r12.py` проверяет:

1. Реальное различие координат предметов между виртуальными тактами,
   отражение от границ и ограничение скорости.
2. Два внешне одинаковых по RGB предмета, **поменявшиеся положениями**
   после 40 тактов, дают разные контактные значения 0,1 и 0,9.
   Настоящие ID используются только самим тестом и зрительским слоем.
3. Сенсор и предполагаемая память организма не содержат истинных ID,
   программных скоростей и скрытых свойств.
4. Одинаковое восстановление событий и checkpoints после рестарта,
   приватность Noosphere и откат при конфликте CAS.
5. CLI `--moving-toys`, отсутствие незаметного перехода к статичной
   комнате, а также совместимость со старым статичным R0.9 журналом.

Критическое ограничение: это **создаёт подвижную среду**, но ещё
**не улучшает автоматически** модель распознавания, которая считает
окрестные объекты примерно неподвижными. Точность повторных
сопоставлений должна отдельно проверяться по oracle-only QA на разных
траекториях, шуме и временных закрытиях обзора. Нельзя называть
возможное повторное сопоставление доказанным распознаванием.

Никаких внешних URL, сетевого API, облачной телеметрии, pretrained
объектной семантики, чтения чужой памяти или прямых сигналов для
моторного железа нет. Запись JSONL является приватной и не должна
автоматически публиковаться. Хэш-цепочка SQLite даёт локальную
проверку целостности, но не независимую криптографическую аттестацию.
