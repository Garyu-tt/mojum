# snnTorch CPU LIF shadow comparator (R01, issue #760)

Status: isolated **draft integration**. The released Aquarium, GENESIS neural authority,
Noosphere PRIVATE SQLite journals, physical actuation and canonical Graph IR are
**not modified**.

## Why this exists

Issue #691 already has separate ANNarchy/Brian2 and Nengo work streams. This
subtask independently tests [snnTorch](https://github.com/jeshraghian/snntorch)
as a *CPU-only research comparator*, **not** a substitute neural substrate.
It runs a small, fixed-input leaky-integrate-and-fire (LIF) population and
compares spike decisions and membrane potentials to an explicit stdlib
reference. No training, STDP, identity, cognition, autonomous movement or
learning is measured.

## Upstream and exact semantics

- Optional [snnTorch **1.0.0**](https://pypi.org/project/snntorch/), MIT
  code license; no vendored upstream content.
- Optional PyTorch CPU wheel, tested-version *target* **2.10.0**,
  [PyTorch BSD-style license](https://github.com/pytorch/pytorch/blob/main/LICENSE).
  This is a proposed native pin and **not** a tested local combination.
- [Documented Leaky implementation](https://snntorch.readthedocs.io/en/latest/_modules/snntorch/_neurons/leaky.html)
  explicitly specifies `reset_delay=True`, `reset_mechanism="subtract"`,
  `surrogate_disable=True`, fixed `beta` and `threshold`.
- Reference timestep: `new_mem = beta * old_mem + current -
  (threshold if old_mem > threshold else 0)`, and a spike iff
  `new_mem > threshold`. This deliberately models the *delayed reset*,
  not a same-tick reset model. Native uses float32 and the stdlib reference
  Python float64; the result is a numerical tolerance check, not
  bit-exact cross-platform replay.

## How to run

The default package has **no new dependencies**. From repository root:

```bash
PYTHONPATH=src python -m unittest discover -s tests -p test_snntorch_shadow.py -v
PYTHONPATH=src python -m mojum.snntorch_shadow --enable --seed 17
```

The optional native experiment runs **only in an explicitly isolated CPU
test environment**. Install manually, after verifying the wheel source:

```bash
python -m pip install snntorch==1.0.0
# Install compatible torch==2.10.0 CPU wheel from the official PyTorch CPU index.
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 PYTHONPATH=src \
  python -m mojum.snntorch_shadow --enable --native --seed 17
```

The wrapper never downloads anything, loads private logs, imports torch
by default, opens sockets or emits motor/GENESIS intentions. Native PyTorch
is a large third-party runtime and **not a security sandbox**; run inside
a network-disabled container with read-only source, an empty unprivileged
home, no hardware device access, memory/CPU/time limits and no credentials.
Merely assigning the string `PUBLIC_SYNTHETIC` is a caller assertion,
not a privacy proof.

## Versioned boundary, budgets, failure modes

- Wire: `mojum.snntorch_shadow/1`. Caller must set `enabled=True`
  and source class exactly `PUBLIC_SYNTHETIC`.
- Fixed shape: **1–128 ticks**, **1–32 neurons**, each current finite in
  [-2,2]. `beta` in [0,0.99999], threshold in [0.5,2].
  Reject ragged, bool, NaN, infinity, overlarge values, unpinned backend,
  unsupported engine and malformed spike/voltage outputs.
- Source SHA-256 covers only normalized inputs and fixed LIF settings;
  stdout reports **metadata only** with explicit
  `motor_authority=false` and `learning_measured=false`.
  Caller must not send PRIVATE arrays even with a fake source label.
- Comparison: exact spikes, membrane max absolute delta <= 1e-5.
  A mismatch is a failed benchmark, **not** permission to fall back to
  neural control or overwrite a journal.
- Small stdlib reference caps to 4,096 neuron-steps. Proposed native
  acceptance envelope: single CPU test process, <=2 CPU threads,
  <=2 GiB RSS and <=30s runtime; **not yet measured** on this host.
  No claim is made for resident GPU/VRAM, on-device suitability,
  power cost or production worker scheduling.
- Always create a fresh model each invocation and start from zero
  membrane. Repeated fixed-seed trials and a second seed must agree.
  Deterministic synthetic currents are generated by a bounded LCG
  independent of wall time, network, identity or old organism state.
- Native dependency absent, wrong version, shape mismatch or
  non-finite output fails closed. Resource-limit enforcement is an
  *external* executor obligation.
