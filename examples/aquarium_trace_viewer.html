Как получить запись

В ветке PR #65 поддерживается --watch, выводящий фактические PRIVATE кадры канонического Aquarium. Пример:

PYTHONPATH=src python -m mojum.aquarium --db ./dante.sqlite3 --ticks 120 --exploration-mode goal_free --sensory-mode toy_probe --watch > ./dante.private.jsonl

Этот просмотрщик читает последовательные кадры схемы mojum.aquarium.frame/1 и пропускает заключительные строки checkpoint. Если у вас только SQLite без заранее сохранённой JSONL-записи, этот HTML не извлекает события напрямую из базы.

Секретные события остаются PRIVATE: не прикладывайте файл к публичным issues. Просмотрщик не проверяет подпись, подлинность журнала или SHA-цепочку. Координаты отображаются для стандартной демонстрационной комнаты 4×4 м; ни препятствия, ни истинные свойства объектов не реконструируются. Это просмотр записи, не автономный Данте и не живая миграция.
